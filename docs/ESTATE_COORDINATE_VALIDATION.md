# 地产坐标实机验证

`LazyForza.EstateProbe` 是独立于 LazyForza 主程序的轻量验证工具。它只读取 FH6 官方 UDP Data Out，用于确认同一个地产在房主、访客、重新进入和下载副本之间是否共享稳定坐标。

## 准备

1. 每台参与验证的电脑运行一份 `LazyForza.EstateProbe.exe`。
2. 在 FH6 的 HUD 与游戏设置中开启 Data Out。
3. 本机验证建议设置 IP 为 `127.0.0.1`，端口为 `2299`；如果这个端口已被占用，可在 FH6 和工具中同时改成另一个避开 `5200–5300` 的端口。
4. 同一 UDP 端口不能同时由 LazyForza 主程序和本工具监听。采集前退出 LazyForza 主程序，或者给验证工具使用另一端口。

## 推荐验证矩阵

至少保存以下会话：

- 房主首次进入；
- 房主退出地产后重新进入；
- 访客进入房主地产；
- 另一名玩家使用下载副本进入。

每个会话都使用完全相同的标记名称。推荐至少选择三个距离较远且不共线的位置，例如：

- `起点`；
- `远端弯角`；
- `维修区入口`；
- 可额外增加一个高低差明显的位置。

车辆在标记物旁完全停稳后，点击“采样最近 1 秒”。离散度最好低于 `0.5 m`。如果标记点位于坡道或车辆很难停稳，应记录同一车身参考位置和朝向。

## 采集步骤

1. 填写会话名称，并选择“房主首次进入”“访客”等身份。
2. 点击“开始新会话”，确认状态变成“正在采集”。
3. 检查实时位置和 `IsRaceOn`、`CurrentLap`、`CurrentRaceTime`、`RacePosition` 是否有值。
4. 依次到达约定标记点，停车并采样。
5. 在赛道内正常驾驶一圈，使工具记录 10 Hz 轻量轨迹并观察坐标突跳。
6. 点击“停止”，补充备注并保存 `.lfzestateprobe.json`。

会话文件包含关键比赛字段、标记点、10 Hz 坐标轨迹和异常计数，不包含账号凭据，也不会上传网络。

## 比较结果

在“比较两份会话”中，通常把“房主首次进入”作为参考会话，再选择访客或重新进入会话。

- **坐标直接一致**：两份数据可以直接使用同一套地产赛道模板。
- **可通过固定刚体变换校准**：只存在水平旋转、平移或固定高度偏移，可以在进入地产时做一次标定。
- **接近可用，仍需复测**：误差偏大，应增加标记点并重复进入地产。
- **当前样本不兼容**：坐标比例、几何关系或稳定性不一致，暂时不应共享赛道模板。

拟合只允许旋转和平移，不会通过缩放强行让两份路线一致。估计比例明显偏离 `1.0` 时应视为坐标空间不兼容或采样点不对应。

## 验证边界

工具只能证明 Data Out 坐标在采样条件下是否稳定，不能证明 FH6 永远保持相同行为。游戏更新、地产布局修订、车辆重置和进入方式都可能改变结果，因此正式支持地产赛道前仍应保留地图修订号和诊断信息。

地产环道的正式录入与几何计时流程见 `ESTATE_CIRCUIT_PHASE1.md`。
