# 设置与侧栏

侧栏保留页面顺序，将设置入口固定在底部。遥测状态旁的数字取自当前运行中的 `TelemetryDiagnostics.ListenPort`；模拟和回放不显示 UDP 端口。入口保持 44 DIP 高，较短窗口压缩快速设置区域，导航区域按需滚动。

快速设置的显示项存储在 `ui.sidebarQuickSettings`，默认显示语音工程师静音，可增加语音音量和减少动态，也可全部隐藏。空数组表示不显示；读取时忽略未知项并去重，旧配置缺少该键时使用默认值。沿用 AppSetting 存储，无数据库结构变更。静音和音量使用工程师已有配置；减少动态使用既有 Overlay 配置，与完整设置同步。

设置页按当前分类创建控件。玩家代号与文本输入在短暂停顿后自动保存，滑块和开关自动应用。连续变更会合并，同一组设置串行应用；切换页面和正常退出前等待最后一次保存完成。无效的监听地址或端口显示输入提示，并保留当前配置。

Live 模式通过现有 `TelemetryHub` 切换 UDP 监听，保留模块订阅。绑定新端口成功后释放旧端口；同端口换地址失败时尝试恢复旧地址。初始端口占用时订阅保持可恢复，修正后继续接收。状态区显示实际运行配置。模拟／回放中编辑监听配置会保存到下一次 Live 启动使用。

语言切换刷新主界面及语音语言配置；数据目录选择自动保存并提示重启，由用户决定时机。备份导入／导出、重置与布局编辑属于独立操作，保留其操作入口。
