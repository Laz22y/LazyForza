# 设置与侧栏

侧栏保留页面顺序，将设置入口固定在底部。遥测状态旁的数字取自当前运行中的 `TelemetryDiagnostics.ListenPort`；模拟和回放不显示 UDP 端口。入口保持 44 DIP 高，较短窗口压缩快速设置区域，导航区域按需滚动。

快速设置的显示项存储在 `ui.sidebarQuickSettings`，默认显示语音工程师静音与 HUD 换挡提示。可选择语音音量、本车换挡推荐、HUD 布局方案、连续实时 Delta、Delta 对比、记录未匹配赛道、HUD 整体不透明度、地产赛事底板不透明度、比赛自动录制及减少动态，也可全部隐藏。原控件旁的图钉与「常规 → 快速设置」勾选列表同步；固定或移除只改变入口，不修改该设置的值。空数组表示不显示；读取时忽略未知项并去重，旧配置缺少该键时使用默认值。沿用 AppSetting 存储，无数据库结构变更。

「当前比赛」顶部始终显示连续实时 Delta 开关和 Delta 对比范围。开关立即生效，默认关闭；对比范围默认为同性能等级最佳，还可选择同赛道、同性能分或同车辆最佳，圈中更改于下圈生效。侧栏分别提供开关和直接选取范围的列表。两项独立于 HUD 布局方案保存，修改它们不会启用圈速分析模块。

「圈速分析」顶部始终显示「记录未匹配赛道」开关，默认关闭。旁边的图钉可将开关固定到侧栏，两处状态同步；设置自动保存，重启后沿用。关闭时停止未匹配路线采集并丢弃当前未完成片段，保留已保存圈记录；中途开启从后续采样开始。设置本身不会启用圈速分析模块，也不影响已收录赛道的正常计圈。

设置页按当前分类创建控件。玩家代号与文本输入在短暂停顿后自动保存，滑块和开关自动应用。连续变更会合并，同一组设置串行应用；切换页面和正常退出前等待最后一次保存完成。无效的监听地址或端口显示输入提示，并保留当前配置。

Live 模式通过现有 `TelemetryHub` 切换 UDP 监听，保留模块订阅。绑定新端口成功后释放旧端口；同端口换地址失败时尝试恢复旧地址。初始端口占用时订阅保持可恢复，修正后继续接收。状态区显示实际运行配置。模拟／回放中编辑监听配置会保存到下一次 Live 启动使用。

监听端口允许 1–65535，建议使用 2299。5200–5300 可能与游戏冲突，首次初始化和设置页会给出可关闭的建议，仍可保存；忽略选择随当前端口保存，修改端口后可再次提醒。无效 IP、超出范围的端口及实际绑定失败仍显示错误。

首次初始化中修改监听 IP 或端口会立即停止旧监听，输入停顿约 0.4 秒后自动监听新端点；右侧显示当前应用进度。旧端点的迟到结果不会完成初始化，绑定失败后可更改设置或点击「重新监听」。

「遥测与录制 → 遥测转发」默认关闭。开启后设置一个目标 IP 与 UDP 端口：同机软件使用 `127.0.0.1`，其他设备使用其 IP；接收端端口需与目标一致。支持 IPv4／IPv6 单播，不能填本机遥测监听端口、未指定地址或组播／广播目标。仅转发通过校验的 Live 原始 324 字节包，模拟与回放不转发；发送失败会继续接收本机遥测并尝试发送后续包。状态显示已发送、队列丢弃与发送错误数，重新启用或更换目标会重置统计；UDP 发送成功不等于对端确认收到。开关和目标随设置保存，应用重新启动后恢复。

语言切换刷新主界面及语音语言配置；数据目录选择自动保存并提示重启，由用户决定时机。备份导入／导出、重置与布局编辑属于独立操作，保留其操作入口。

更换数据目录时会带上当前有效车辆名称库，目标目录已有较新版本时保留目标版本。配置或车辆备份也包含名称库，导入时按版本选用较新的有效数据；其余个人数据通过原有备份选项迁移。
