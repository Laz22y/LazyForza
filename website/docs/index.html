01 / QUICK START

快速开始

下载与安装

从 GitHub Releases 或官网的 GitCode 入口下载安装版。需要免安装使用时，选择 win-x64.zip 便携版并完整解压。两种版本都已包含 .NET 运行时。

不要在 ZIP 内直接运行

更新、日志、数据库和录制需要正常的可写目录。

配置 FH6 Data Out

  1. 1
    打开设置

    进入 FH6“设置 > HUD 与游戏玩法”。

  2. 2
    开启 Data Out

    地址填写 127.0.0.1。

  3. 3
    设置端口

    端口填写 2299，返回驾驶。

第一次使用

  • 只开启当前需要的 HUD 部件；
  • 用布局编辑器调整位置、缩放和透明度；
  • 正常完成几圈，让程序建立车辆与赛道记录；
  • 确实需要复盘时再开启自动录制。

02 / CLIENT

客户端功能

LIVE HUD

实时仪表盘

速度、挡位、转速、踏板、方向、轮胎、动力和性能等级可独立开关、移动、缩放与调节透明度。窗口支持置顶和鼠标穿透。

LAP ANALYSIS

圈速与走线

按距离对齐单圈，联动速度、油门、制动、方向与走线。紫色分段只表示本地同等级最快，不代表在线世界纪录。

VEHICLE

车辆与换挡学习

按车型、性能等级和可观测调校特征保存结果。车辆名称映射使用 HDR 提供的 Car Ordinals 文档内置快照。

RECORDING

录制与回放

自动录制默认关闭。可保留赛前 15 秒与赛后 10 秒；回放工作台联动时间轴、驾驶输入、走线和动态遥测。

DRIFT

实验性漂移 HUD

用本车 UDP 推导侧滑角和控车趋势，优先降低 Spin 风险。换挡箭头不是最佳换挡点，积分趋势不复刻游戏分数。

ESTATE RACE

地产环道与赛事

录入支持暂存、地图预览和分项修订；赛事 HUD 提示弱网状态，服务端可选开启断线计圈恢复。

使用 --data-dir 指定独立目录：

LazyForza.App.exe --data-dir "D:\LazyForza_Data"

隐私边界

  • 默认不要求账号，个人数据保存在本机；
  • 只有主动连接 RaceServer 时，赛事所需资料和遥测摘要才发送到该服务器；
  • 不伪造官方 UDP 未提供的赛道 ID、调校 ID、车辆尺寸或轮胎位置；
  • 录制容量、轮换、备份和更新均由用户控制。

更新

正式安装版默认启动检查更新，正式便携版默认关闭，两者都可在设置中修改。正式版只提示、不强制安装，下载优先使用 GitCode，失败时回退 GitHub。预览版使用独立初始化状态和 GitCode/GitHub 预发布更新通道，每次启动强制检查并自动安装可用更新；可独立选择首选来源，失败时自动切换备用来源。检查或安装失败时需重试或退出。安装前均校验发行包 SHA-256 和包内清单，失败时恢复原版本。

04 / RACESERVER

RaceServer

RaceServer 是独立项目，只进行日常驾驶和圈速分析时无需安装。

1–12参赛车手
12额外 OB 席位
2部署方式
v2赛事协议

提供什么

  • 1–3 节练习与排位、正赛、五盏红灯和方格旗；
  • 车队、维修区、旗语、处罚、碰撞调查、路线收益切弯证据、OB 和可选断线计圈恢复；
  • 阶段赛果归档，返回大厅后仍可回看并导出 PNG/CSV；
  • 超管、管理员和裁判多账号分权；同一角色可创建多个独立账号；
  • 适配电脑宽屏和 Pad 触控的浏览器总控。

模拟换胎

地产赛事的换胎流程使用游戏内设置模拟。依次进入维修区和换胎区，车辆停稳后暂停游戏，打开“设置 → 难度”，将“损坏与轮胎磨损”调为“外观”并保存；随后调回“拟真”，再次保存并返回游戏。LazyForza 只核对车辆位置和停留条件，不读取暂停菜单，也无法确认游戏内设置是否完成。

方式适合场景维护要求

原生服务端

从 RaceServer Releases 下载对应平台 ZIP。支持 win-x64、linux-x64、linux-arm64、osx-x64 和 osx-arm64。

# Windows
./LazyForza.RaceServer.Web.exe
# Linux / macOS
chmod +x ./LazyForza.RaceServer.Web
./LazyForza.RaceServer.Web

默认监听 http://0.0.0.0:24876。首次打开网页时设置房间密码、初始超管密码和赛事规则，不要求设置其他角色；超管之后可按需创建管理员、裁判或更多超管账号。公网部署应由 Caddy、Nginx 或同类反向代理终止 TLS，让客户端连接 wss://。

Cloudflare 部署

在服务端仓库使用 Deploy to Cloudflare，或运行：

./scripts/Deploy-Cloudflare.ps1

需要 Node.js 20+、npm 和 PowerShell 7。部署后打开 Worker 域名完成首次设置，再上传 .lfzestate 赛道文件。

客户端连接

车手需要服务端域名或 IP、房间密码、匹配的地产赛道、显示名和可选车队。客户端可收藏常用服务器，并在进入房间前测试服务端可达性、协议版本和房间信息；收藏不会保存赛事密码。OB 只接收赛事快照，不上传遥测、不参与排名和处罚。

兼容性

RaceServer 0.4.3 推荐搭配 LazyForza 1.5.0，并兼容 1.4.2–1.4.9 的协议 v2 主要流程。断线计圈恢复需要客户端 1.4.8 或更高版本，并由服务端总控开启。

05 / TROUBLESHOOTING

常见问题

客户端一直显示没有遥测

确认 FH6 已开启 Data Out，IP 为 127.0.0.1，端口为 2299。检查端口占用和本机防火墙；游戏与 LazyForza 的端口必须一致。

HUD 没有显示或位置错误

确认对应 HUD 已开启。进入布局编辑器检查显示器、位置、缩放和透明度；多显示器或分辨率变化后可先恢复默认布局。

赛道没有自动识别

先完成一段稳定驾驶，避免倒车、重置、暂停和大幅偏离路线。用户自定义路线需要单独录入；无法可靠区分时程序会要求人工确认。

自动录制停止

检查录制目录空间和容量上限。默认达到上限后停止，不自动删除；需要轮换时由用户明确开启。

无法连接 RaceServer

检查地址、房间密码和协议版本。公网环境需要 HTTPS/WSS，反向代理必须转发 WebSocket Upgrade。网页能打开不代表 WebSocket 一定可用。

更新失败

保留提示和 %LOCALAPPDATA%\LazyForza\Logs。重新下载完整 ZIP 并解压到新目录即可；个人数据默认不在程序目录中。

07 / PROTOCOL

协议字段边界

FH6 官方 Data Out 固定为 324 字节。可以直接获得位置、速度、姿态、输入、动力、悬挂和轮胎状态等字段，但不提供：

  • 官方赛道 ID 和赛事 ID；
  • 对手车辆遥测；
  • 调校 ID、宽体或精确车辆几何。

开发时以官方字段定义为准。推导数据必须与官方字段明确区分。
