CAPABILITIES

从实时信息，到可复盘的数据。

日常驾驶、练习、单圈分析和地产赛事使用同一套本地数据链路。
LIVE / 01

自由布局的实时 HUD

速度、挡位、转速、踏板、轮胎、动力和换挡提示可独立开关、移动、缩放与调节透明度。

ANALYZE / 02

圈速与走线对比

按距离联动速度、油门、制动、方向和走线，定位每一段时间差的来源。

REFERENCE−0.284
REPLAY / 03

录制与回放

可选自动录制保留赛前与赛后片段；回放工作台联动时间轴、驾驶输入和动态遥测。

LEARN / 04

车辆与换挡学习

按车型、性能等级和可观测调校特征保存学习结果，在信息不足时保持保守。

RACE / 05

地产环道赛事

可暂存和分项修订环道录入；赛事端提供弱网提醒、可选断线计圈恢复与赛果归档。

DATA / 06

可控的数据与更新

数据目录、备份、录制容量和自动更新都由用户控制；更新包同时校验外部哈希与内部清单。

QUICK START

三步开始。

  1. 01下载并完整解压

    运行 LazyForza.App.exe，无需另装 .NET 运行时。

  2. 02开启 FH6 Data Out

    地址设为 127.0.0.1，端口设为 2299。

  3. 03进入驾驶

    实时 HUD 自动连接；圈速、赛道与车辆数据按功能设置保存。

RACESERVER

需要办赛时，再部署服务端。

RaceServer 是独立项目。它提供 1–12 名车手、OB、练习与多节排位、正赛控制、旗语、处罚调查、维修区和阶段赛果归档。

01只使用官方 Data Out

不读取游戏内存，不修改游戏进程，不注入 DLL。

02不虚构缺失数据

官方 UDP 不提供的赛事 ID、车辆尺寸和轮胎位置不会被伪装成官方数据。

03发行可核验
